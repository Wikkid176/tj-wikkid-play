Eight story chapters, co-op, Fighter Mode, HD and Old School views, and the
unlockable *Urban Legend* album. Browser play supports keyboard, touch and
controllers; phones work best in landscape.

The Windows setup contains the complete game and works offline after download.
No installation password is required. Game assets use authenticated AES-256-GCM
encryption. Passwordless software contains its runtime key; this is not
unextractable DRM or code signing. Uninstalling preserves your saves.
